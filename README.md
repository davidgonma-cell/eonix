# EONIX — Longevidad

App de biohacking basada en la ciencia de las Zonas Azules.

## 🚀 Cómo publicar en GitHub Pages (5 pasos)

### Paso 1 — Crear el repositorio
1. Ve a [github.com/new](https://github.com/new)
2. Ponle un nombre, por ejemplo: `eonix-app`
3. Marca **Public**
4. Haz clic en **Create repository**

### Paso 2 — Subir los archivos
En la página del repositorio vacío:
1. Haz clic en **"uploading an existing file"**
2. Arrastra estos dos archivos:
   - `index.html`
   - `README.md`
3. Haz clic en **Commit changes**

### Paso 3 — Activar GitHub Pages
1. Ve a **Settings** (arriba a la derecha del repositorio)
2. En el menú izquierdo: **Pages**
3. En "Source" selecciona: **Deploy from a branch**
4. Branch: **main** / Folder: **/ (root)**
5. Haz clic en **Save**

### Paso 4 — Esperar 1-2 minutos
GitHub construye la web automáticamente.

### Paso 5 — Tu URL pública
```
https://TU_USUARIO.github.io/eonix-app/
```
¡Cópiala y ábrela desde el móvil!

## 📱 Instalar como app en el móvil

### iPhone (Safari)
1. Abre la URL en Safari
2. Toca el botón **Compartir** (cuadrado con flecha)
3. Toca **"Añadir a pantalla de inicio"**

### Android (Chrome)
1. Abre la URL en Chrome
2. Toca el menú **⋮** (tres puntos)
3. Toca **"Añadir a pantalla de inicio"**
